# 毕设方案定稿（方案 B 轻量版）

> 2026-11-03 讨论定稿。题目：《基于大语言模型的个性化旅游攻略生成软件的设计与实现》。
> 项目名：途忆（英文仓库名 tuyi），智能体昵称「小忆」。

## 一、总体形态

Node 复用 Momo 大脑（流式 DeepSeek + 工具循环）＋ Web 三页（聊天 / 偏好统计看板 / 个人中心）＋ Python 两模块（记忆消化、偏好统计）。

- LLM：DeepSeek API（沿用 Momo 的模型与流式写法）
- 景点 / 天气：高德开放平台 POI + 天气 API
- 存储：本地 JSON（无数据库）
- 创新点：记忆消化（反思合成，轻量版：记忆攒到约 10 条触发一次反思，输出固定 JSON 偏好标签 + 摘要，注入提示词）
- 大数据元素：用户偏好统计分析（pandas + 看板），数据源就是记忆消化产出的结构化偏好标签

## 二、任务 - 论文映射

| 任务书要求 | 落点 |
|---|---|
| 接入 LLM API + 流式响应 | brain/llm.js + server.js 的 SSE |
| 接入景点数据做地理约束 | tools/ 下的高德 POI 与天气工具 |
| 系统功能实现与可视化 | 行程卡片 + 偏好统计看板 |
| 提示工程 | brain/prompts/（人设 + plan_trip 规范） |
| 解决幻觉 | 结构化 JSON 校验 + POI 数据约束 + 检索增强 + 消融实验 |
